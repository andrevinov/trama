# Roadmaps de implementação

[Visão geral](../../README.md) · [Política de documentação](../sistema/qualidade/documentacao.md)

Planos ficam separados da documentação do funcionamento atual. Cada iniciativa
ocupa uma pasta com objetivo, passos, critérios, resultado e links para as
referências entregues. Materiais auxiliares acompanham o plano.

- [Não implementados](nao-implementados/README.md): propostas aguardando início.
- [Em implementação](em-implementacao/README.md): trabalho iniciado e acompanhado.
- [Implementados](implementados/README.md): arquivo por data de conclusão.

A pasta muda de estado com o trabalho. Ao concluir, atualize primeiro os
documentos do sistema e arquive em `implementados/AAAA-MM-DD-nome`.
Resultados de experimentos ficam em [evidências](../evidencias/README.md).
